[es] Área de triángulos
El área de un triángulo es (base × altura perpendicular) / 2. Con base 8 cm y altura 3 cm, el área es 12 cm². Multiplicar solo base por altura daría 24 cm² y omitiría dividir entre dos.

[es] Descomposición visual
Un rectángulo de base 8 cm y altura 3 cm tiene área 24 cm². Una diagonal lo divide en dos triángulos de igual área; cada triángulo ocupa la mitad: 12 cm². Esta descomposición explica el factor 1/2.

[es] Base y altura perpendicular
Puedes elegir cualquiera de los lados de un triángulo como base. Desde el vértice opuesto, traza un segmento perpendicular a la recta que contiene esa base: forma un ángulo de 90 grados. La longitud de ese segmento es la altura correspondiente a la base elegida. Si cambias la base, debes identificar de nuevo su altura correspondiente. Un lado inclinado no es la altura a menos que sea perpendicular a la base. La altura puede quedar dentro o fuera del triángulo; prolonga la recta de la base si es necesario. Por ejemplo, si eliges una base de 8 cm y el segmento perpendicular mide 3 cm, usa 3 cm como altura, aunque otro lado mida 5 cm. Para identificar base y altura no necesitas calcular el área.
